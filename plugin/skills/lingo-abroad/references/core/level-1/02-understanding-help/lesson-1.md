# Level 1 · Understanding & Getting Help · Lesson 1: When You Don't Understand (shared spec)

**Goal:** stay calm when a local talks too fast: ask if they speak English, say you don't understand, ask them to slow down or repeat, and read the signs you need on day one (information, restrooms, women / men). About 7 minutes.

This spec lists **meanings**, not words. Write each item in the target language as a polite local would say it in the destination country (see SKILL.md, Writing the items).

## Speak — what you say

| # | Meaning | When | Target-language note |
| :- | :------ | :--- | :------------------- |
| S1 | "I don't understand." | Any time you're lost | |
| S2 | "Do you speak English?" | Before switching to English: always ask, never assume | Polite form (e.g. Italian _Parla…?_, not _Parli…?_). Use the learner's language if it isn't English. |
| S3 | "More slowly, please." | Someone speaks too fast | |
| S4 | "Can you repeat, please?" | You almost got it | Polite form. |

## Listen — what locals say back

| # | Meaning | Situation |
| :- | :------ | :-------- |
| L1 | "Yes, a little." | Answering S2 |
| L2 | "Pardon?" / "What?" | They didn't catch you |
| L3 | "Do you understand?" | Checking after explaining |

## Read — what you'll see

| # | Meaning | Where | Target-language note |
| :- | :------ | :---- | :------------------- |
| R1 | Information | Desks at stations, airports, museums | |
| R2 | Restrooms / Toilets | Signs and doors in stations, cafés, museums | Teach the most common word; mention the others once if there are several (e.g. Italy: _Bagno_, _Toilette_, _WC_, _Servizi_). |
| R3 | Women / Men | Restroom doors | Teach both words as one pair. **Trap:** where the two words look alike, point it out (e.g. Italy: _Donne / Uomini_, but also _Signore_ = women, _Signori_ = men, one letter apart). |
| R4 | Tourist office | Town centers, stations | |

## Roleplay — 3 short scenes

1. **Info desk:** "You're at the station information desk. The clerk greets you and says something fast in the language." → learner: "excuse me" (Basics) + S2. Clerk: L1.
2. **Too fast:** the clerk answers quickly again (a platform number and a time) → learner: S1 + S3. Clerk repeats it slowly.
3. **Almost got it:** the clerk says the platform once more, quickly, + L3 → learner: S4. Clerk repeats it slowly → learner: thank you (Basics). **(Extras on)** curveball: the clerk adds "The restrooms are over there" and points; ask the learner which sign to look for (R2, then R3).
