# Level 1 · Transport · Lesson 3: Train (shared spec)

**Goal:** buy a single or return train ticket, find the platform, and make sure you're on the right train. About 7 minutes.

This spec lists **meanings**, not words. Write each item in the target language as a polite local would say it in the destination country (see SKILL.md, Writing the items).

## Speak — what you say

| # | Meaning | When | Target-language note |
| :- | :------ | :--- | :------------------- |
| S1 | "A return ticket to <city>, please." (and "one-way") | Ticket office | Use a real city a train ride away from the destination. Teach "return" as the main form and "one-way" as its pair. |
| S2 | "Which platform does it leave from?" | Ticket office, info desk, staff | |
| S3 | "Is this the train to <city>?" | Before boarding; ask a conductor or passenger | |

## Listen — what locals say back

| # | Meaning | Situation |
| :- | :------ | :-------- |
| L1 | "One-way or return?" | The ticket clerk |
| L2 | "Yes, it's this one." / "No, it's that one." | Answering S3 (pointing) |
| L3 | "Tickets, please." | The conductor on board |

## Read — what you'll see

| # | Meaning | Where |
| :- | :------ | :---- |
| R1 | Platform / track | Departure board, platform signs |
| R2 | Ticket office | Station hall |
| R3 | Delayed | Departure board |
| R4 | Underpass / To the platforms | Signs in the station |

**Local train note (one sentence, once):** anything that catches visitors out (e.g. Italy: paper regional tickets must be validated in the green or yellow machine on the platform before boarding; e-tickets and high-speed tickets don't need it).

## Roleplay — 3 short scenes

1. **Ticket office:** "You're going to <city> for the day. Clerk: greeting + 'What would you like?'" → S1 (if the learner forgets the type, clerk asks L1). Clerk: "Here you are." → learner: thank you.
2. **The platform:** "Ask the clerk which platform it leaves from." → S2. Clerk: "Platform <number>." Then: "The board says [Delayed] next to your train. What does it mean?" (R3).
3. **Right train?** "On the platform, a conductor stands by a train." → learner gets attention (Basics) + S3. Conductor: L2 ("No, it's that one"). Later, on board: L3 → learner: "Here you are" or "Please" (Basics).
