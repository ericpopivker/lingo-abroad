# Level 1 · Transport · Lesson 2: Bus & Metro (shared spec)

**Goal:** buy a ticket, check a bus or metro line goes where you want, and know where to get off. About 7 minutes.

This spec lists **meanings**, not words. Write each item in the target language as a polite local would say it in the destination country (see SKILL.md, Writing the items).

## Speak — what you say

| # | Meaning | When | Target-language note |
| :- | :------ | :--- | :------------------- |
| S1 | "One ticket, please." | At a ticket window, machine help desk or shop that sells tickets | |
| S2 | "Which line goes to …?" | At a stop or a metro map | Practice with a well-known sight in the destination city. |
| S3 | "Does this bus go to …?" | Before boarding; ask the driver | |
| S4 | "Where do I get off?" | On board; ask the driver or a passenger | |

## Listen — what locals say back

| # | Meaning | Situation |
| :- | :------ | :-------- |
| L1 | "Yes, it goes to the center." | The driver answering S3 |
| L2 | "At the next stop." | Answering S4 |
| L3 | "You need to validate the ticket." | A clerk or driver, where tickets must be stamped. If the country doesn't validate tickets, use "Tap your card here." |

## Read — what you'll see

| # | Meaning | Where |
| :- | :------ | :---- |
| R1 | Stop (bus / tram) | Pole or shelter at the stop |
| R2 | Where tickets are sold | Shop sign or machine (e.g. Italy: _Tabacchi_, the big "T" sign) |
| R3 | Validate your ticket | Machine on board or on the platform (if the country has one) |
| R4 | Metro / subway | Station entrance (e.g. a big "M") |

**Local ticket note (one sentence, once):** how tickets work in the country (e.g. Italy: buy before boarding at _Tabacchi_ or machines, validate on board; inspectors fine unvalidated tickets).

## Roleplay — 3 short scenes

1. **Buying a ticket:** "You walk into the shop that sells tickets. Clerk: greeting + 'What would you like?'" → S1. Clerk: "Here you are" + L3 → learner: thank you.
2. **At the stop:** "A bus pulls up. Ask the driver if it goes to the center." → S3. Driver: L1. Then: "In the metro, ask which line goes to <a famous sight>." → S2.
3. **On board:** "You don't know your stop. Ask the driver." → S4. Driver: L2 → learner: thank you.
