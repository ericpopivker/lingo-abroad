# Level 1 · Basics · Lesson 3: Polite Basics (shared spec)

**Goal:** say yes/no and OK, get someone's attention, and get past people politely. About 7 minutes.

This spec lists **meanings**, not words. Write each item in the target language as a polite local would say it in the destination country (see SKILL.md, Writing the items).

## Speak — what you say

| # | Meaning | When | Target-language note |
| :- | :------ | :--- | :------------------- |
| S1 | Yes | Answering any question | |
| S2 | No | Answering any question | If it's the same word as in the learner's language, say so in one sentence and move on quickly. |
| S3 | "Excuse me" / "Sorry" (to get attention) | Getting a waiter's or stranger's attention; small apology | The polite form for strangers. |
| S4 | "Excuse me" (may I pass?) | Squeezing past people on a bus or in a shop aisle | Only if the language uses a different phrase from S3 for this; otherwise teach S3 for this use too and say so in one sentence. |
| S5 | "OK" / "That's fine" | Agreeing to anything | |

## Listen — what locals say back

| # | Meaning | Situation |
| :- | :------ | :-------- |
| L1 | "I'm sorry, it's closed." | Asking about a shop, the restroom, a counter |
| L2 | "Of course!" / "Sure!" | Staff agreeing to a request |
| L3 | "One moment." | Staff asking you to wait |

## Read — signs you'll see

| # | Meaning | Where |
| :- | :------ | :---- |
| R1 | Caution / Attention | Wet floor, steps, works |
| R2 | Private | Staff-only doors |
| R3 | Out of order (broken) | Ticket machines, restroom doors |
| R4 | Out of service | Lifts, escalators, buses |

## Roleplay — 3 short scenes

1. **Crowded bus:** "You need to get off, but people block the door." → learner: S4 (accept S3 if the language uses one phrase for both).
2. **Calling the waiter:** "You're at a café table and want the waiter." → learner: S3. Waiter: L2 + L3.
3. **Agreeing:** Waiter offers a coffee ("A coffee?") → learner: S1 (yes) + S5. Waiter: "Anything else?" → learner: S2 (no) + "thank you" (from Lesson 2). Waiter, later: "Sorry, the restroom is out of order" (L1 wording + R3 word) → learner: S5 + "thank you".
