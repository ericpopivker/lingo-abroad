# Level 1 · Basics · Lesson 1: Greetings (shared spec)

**Goal:** greet and say goodbye politely in any shop, café or hotel. About 7 minutes.

This spec lists **meanings**, not words. Write each item in the target language as a polite local would say it in the destination country (see SKILL.md, Writing the items).

## Speak — what you say

| # | Meaning | When | Target-language note |
| :- | :------ | :--- | :------------------- |
| S1 | Polite hello (daytime) | Arriving at a shop, café or hotel desk, until about mid-afternoon | The safe hello to staff and strangers. If the language has one polite hello for all day, teach it here and skip S2. |
| S2 | Polite hello (evening) | Arriving from mid/late afternoon on | Only if the language switches greeting by time of day. |
| S3 | Polite goodbye | Leaving a shop, café or hotel desk | The goodbye used with staff and strangers, not the casual one used with friends. |

## Listen — what locals say back

| # | Meaning | Situation |
| :- | :------ | :-------- |
| L1 | "Hello, how can I help?" | A shopkeeper greets you as you walk in |
| L2 | "Have a nice day!" | Staff, as you leave |
| L3 | "Goodbye, have a nice evening!" | Staff, as you leave in the evening |

## Read — signs you'll see

| # | Meaning | Where |
| :- | :------ | :---- |
| R1 | Open | Shop door |
| R2 | Closed | Shop door |
| R3 | Entrance | Door, museum, station |
| R4 | Exit | Door, museum, station |

## Roleplay — 3 short scenes

Set each scene in one sentence (in the destination city), play the local, wait for the reply:

1. **Morning arrival:** "Nine in the morning. You walk into a café. I'm the barista." Greet the learner with S1 → learner: S1.
2. **Evening arrival:** "Six in the evening. You walk into a small shop. I'm the shopkeeper." Greet with S2 (or S1 if the language has one hello) → learner: S2.
3. **Leaving:** "You pay and head out. Shopkeeper: L3 (or L2)." → learner: S3.

If the learner uses a casual greeting: give the polite one for that moment (arriving vs. leaving), have them repeat it, mark it Weak.
