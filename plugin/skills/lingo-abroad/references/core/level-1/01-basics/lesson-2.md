# Level 1 · Basics · Lesson 2: Please, Thank You, You're Welcome (shared spec)

**Goal:** ask for things politely by pointing, thank people, and answer a thank-you. About 7 minutes.

This spec lists **meanings**, not words. Write each item in the target language as a polite local would say it in the destination country (see SKILL.md, Writing the items).

## Speak — what you say

| # | Meaning | When | Target-language note |
| :- | :------ | :--- | :------------------- |
| S1 | "This one, please." | Pointing at a pastry, a ticket, anything on a counter | Works everywhere; the most useful phrase in the course. |
| S2 | "Thank you" / "Thank you very much" | Any time | Teach the plain form and the warmer form if the language has one. If the form changes with the speaker's gender, use the learner's form from the card. |
| S3 | "You're welcome." | When someone thanks you (e.g. you held the door) | |

## Listen — what locals say back

| # | Meaning | Situation |
| :- | :------ | :-------- |
| L1 | "Yes? What would you like?" | Staff inviting you to order |
| L2 | "Here you are." | Handing you something |
| L3 | "Don't mention it." | A polite reply to your thanks |

## Read — signs you'll see

| # | Meaning | Where |
| :- | :------ | :---- |
| R1 | Please wait | Counter, ticket office |
| R2 | No smoking | Anywhere indoors, stations |
| R3 | Do not touch | Shops, museums |
| R4 | The polite "please…" wording that starts notices | Notices on doors and walls. If signs in the language don't use one, use **Push / Pull** instead. |

## Roleplay — 3 short scenes

1. **Bakery:** "You're at a bakery counter, pointing at a pastry. I'm the baker." Greet politely + L1 → learner: S1.
2. **Getting served:** "The baker hands it over: L2." → learner: S2.
3. **Holding the door:** "On your way out you hold the door for a lady. She thanks you." → learner: S3.

If the learner says "thank you" when someone thanks them, gently give S3 and have them repeat it.
