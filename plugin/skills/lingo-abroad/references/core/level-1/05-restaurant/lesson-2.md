# Level 1 · Restaurant · Lesson 2: Menu & Dietary Needs (shared spec)

**Goal:** ask what a dish is, get a recommendation, and say what you can't eat. About 7 minutes.

This spec lists **meanings**, not words. Write each item in the target language as a polite local would say it in the destination country (see SKILL.md, Writing the items).

## Speak — what you say

| # | Meaning | When | Target-language note |
| :- | :------ | :--- | :------------------- |
| S1 | "What is this?" | Pointing at something on the menu or a counter | |
| S2 | "What do you recommend?" | Can't decide | Polite form to the waiter. |
| S3 | "I'm vegetarian." | Ordering | If the form changes with the speaker's gender, use the learner's form from the card. |
| S4 | "I'm allergic to…" (+ nuts, gluten, etc.) | Ordering, if it applies | Teach the frame plus one common allergen; if the learner has a real allergy, teach theirs and add it to **My phrases**. Add once, as a friendly tip: "Tip: show it written down too. It helps the staff get it right." |

## Listen — what locals say back

| # | Meaning | Situation |
| :- | :------ | :-------- |
| L1 | "I recommend the…" / "The house specialty is…" | After you ask for a recommendation |
| L2 | "It's made with…" / "It has meat / fish in it." | After you ask what a dish is |
| L3 | "I'll check with the kitchen." | After you mention an allergy |

## Read — what you'll see

| # | Meaning | Where |
| :- | :------ | :---- |
| R1 | Dish of the day / Today's specials | Board outside or menu insert |
| R2 | Vegetarian | Menu label or symbol |
| R3 | Allergens / Contains… | Bottom of the menu, food labels |
| R4 | Homemade | Menu, shop windows |

## Roleplay — 3 short scenes

1. **Unknown dish:** "You see a dish you don't know on the menu. I'm the waiter." → learner points: S1. Waiter: L2 (describe a simple local dish).
2. **Can't decide:** → learner: S2. Waiter: L1 → learner orders it with "I'd like…" (Lesson 1).
3. **Dietary need:** "Your friend can't eat meat" (or the learner's own need) → learner: S3 or S4. Waiter: L3, then "No problem."
