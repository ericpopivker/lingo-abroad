# Level 1 · Restaurant · Lesson 1: Ordering (shared spec)

**Goal:** get a table, order food and drinks, and answer the waiter's usual questions. About 7 minutes.

This spec lists **meanings**, not words. Write each item in the target language as a polite local would say it in the destination country (see SKILL.md, Writing the items).

## Speak — what you say

| # | Meaning | When | Target-language note |
| :- | :------ | :--- | :------------------- |
| S1 | "A table for two, please." | Arriving at a restaurant or café with table service | Teach "for two"; mention once that the learner can swap in any number they know. |
| S2 | "I'd like…" (+ a dish or drink) | Ordering anything | The polite "I would like", not "I want" or "give me". Practice it with one simple dish or drink of the country. |
| S3 | "Still water, please." | Ordering water | If water isn't usually ordered this way in the country, teach the common way to ask for (tap or bottled) water. |
| S4 | "That's all, thank you." | When the waiter asks if you want anything else | |

## Listen — what locals say back

| # | Meaning | Situation |
| :- | :------ | :-------- |
| L1 | "Do you have a reservation?" | Arriving at a restaurant |
| L2 | "What are you having?" / "What would you like?" | The waiter ready to take your order |
| L3 | "Still or sparkling?" | After you order water. If locals don't ask this, use "Anything else?" instead. |

## Read — what you'll see

| # | Meaning | Where |
| :- | :------ | :---- |
| R1 | Menu | Card on the table, board outside |
| R2 | Starters | Menu heading |
| R3 | Main courses | Menu heading. Use the country's real headings (e.g. Italy has first and second courses) |
| R4 | Reserved | Sign on a table |

## Roleplay — 3 short scenes

1. **Arriving:** "Eight in the evening. You walk into a busy trattoria. I'm the waiter." Greet politely + L1 → learner: (greeting) + S1.
2. **Ordering:** "You're seated with the menu. Waiter: L2." → learner: S2 + a dish.
3. **Drinks:** Learner orders water → waiter: L3 → learner: S3. Waiter: "Anything else?" → learner: S4.

If the learner says "I want…": give S2 instead and have them repeat it.
