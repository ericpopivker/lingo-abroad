# Level 1 · Restaurant · Lesson 3: The Bill (shared spec)

**Goal:** compliment the food, ask for the bill, pay, and understand what's on it. About 7 minutes.

This spec lists **meanings**, not words. Write each item in the target language as a polite local would say it in the destination country (see SKILL.md, Writing the items).

## Speak — what you say

| # | Meaning | When | Target-language note |
| :- | :------ | :--- | :------------------- |
| S1 | "It's delicious!" | The waiter checks on you, or as you pay | |
| S2 | "The bill, please." | When you're ready to pay | In many countries you must ask; the bill won't come on its own. Say so once if true for the country. |
| S3 | "Can I pay by card?" | Paying | |
| S4 | "Separately, please." / "Can we pay separately?" | Splitting the bill | If splitting is unusual in the country, say so once. |

## Listen — what locals say back

| # | Meaning | Situation |
| :- | :------ | :-------- |
| L1 | "Is everything all right?" / "Was everything good?" | The waiter checking on you |
| L2 | "Cash or card?" | Paying |
| L3 | "Service is included." / "Service isn't included." | Paying, if you ask or look surprised |

## Read — what you'll see

| # | Meaning | Where |
| :- | :------ | :---- |
| R1 | Bill / Receipt | The paper you're handed. If everyday receipts have their own word, teach that one (e.g. Italy: _scontrino_ at café and shop tills; _conto_ for the restaurant bill) |
| R2 | Cover charge (per person) | On the bill, where it exists (e.g. Italy's _coperto_). If the country has none, use **Total** |
| R3 | Service (charge) | On the bill or menu |
| R4 | Cashier / Pay here | Counter in cafés and bars |

**Local tipping norm:** in the wrap-up or when L3 comes up, say the country's norm in one sentence (e.g. Italy: tipping isn't expected; rounding up or a few coins for good service is fine).

## Roleplay — 3 short scenes

1. **Checking in:** "You're halfway through your pasta. Waiter: L1." → learner: S1.
2. **The bill:** "You're done. The waiter is across the room." → learner gets attention (Basics) + S2.
3. **Paying:** "The waiter brings the bill. You're with a friend." → learner: S4 (optional) + S3. Waiter: L2 → learner answers (card). Waiter, leaving: "Thank you, have a nice evening!" → learner: goodbye (Basics).
