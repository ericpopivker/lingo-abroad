# Level 1 · Shopping · Lesson 1: How Much (shared spec)

**Goal:** count to ten, ask for things by number and ask what they cost, and understand the price said back (tens, euros and cents). About 7–8 minutes.

This spec lists **meanings**, not words. Write each item in the target language as a polite local would say it in the destination country (see SKILL.md, Writing the items). Use the country's currency (euro in Italy and Portugal).

## How to teach the number blocks (S1, S2, L1)

Numbers are taught as **runs**, not separate phrases, so the lesson stays about 7–8 minutes:

1. Signpost "Numbers, 1 to 5." Say the run slowly with a short pause between numbers → "Your turn." → the learner says the whole run. If they miss one, say just that number and have them repeat it.
2. Memory tricks **only for the hard ones** (one sentence each, after they repeat), e.g. Italian _sei_ = **six**, _otto_ = an **octo**pus has eight legs.
3. Quick check: three numbers from the run out of order ("What's _quattro_?"), one at a time.
4. Same for "Numbers, 6 to 10."
5. **Tens (L1) are for listening only:** say 10, 20 … 100 slowly, then quiz three out of order ("What's _cinquanta_?"); tricks only for the hard ones (e.g. Italian _cento_ = a **cent**ury, a hundred). The learner doesn't have to say them.

On the card each run is **one item**: "numbers 1–5 (S)", "numbers 6–10 (S)", "tens 10–100 (L)". A run is right when the learner gets all of it with at most one slip. Numbers above 10 said aloud, big numbers and saying prices yourself are Level 2.

## Speak — what you say

| # | Meaning | When | Target-language note |
| :- | :------ | :--- | :------------------- |
| S1 | Numbers 1–5 (run) | Counting anything | Teach the counting form (e.g. Italian _uno_), and mention once that "one" changes before a noun if it does. |
| S2 | Numbers 6–10 (run) | Counting anything | |
| S3 | "How much is it?" | Shops, markets, kiosks | If the learner knows it from Transport ("How much is it to the center?"), it's a quick recall, not a new item. |
| S4 | "<Number> of these, please." (pointing) | Pastries, fruit, postcards | Practice with numbers 2–5. |

## Listen — what locals say back

| # | Meaning | Situation |
| :- | :------ | :-------- |
| L1 | Tens 10–100 (listening run) | Prices, amounts |
| L2 | "<N> euros <N>." (a price with cents, e.g. "Eight fifty.") | Answering S3. Build every price from taught numbers only: euros 1–10 or a ten, cents a ten (e.g. 4.50, 8.20, 20.50); never 11–19. |
| L3 | "How many?" | Counter staff, market sellers |

## Read — what you'll see

| # | Meaning | Where |
| :- | :------ | :---- |
| R1 | A price tag in local format | Shop windows, menus (note once if decimals use a comma, e.g. Italy: € 8,50) |
| R2 | Sale / Discount | Shop windows, price tags (e.g. Italy: _Saldi_, _Sconto_) |

## Roleplay — 3 short scenes

1. **Bakery:** "You point at the pastries. Baker: greeting + L3." → S4 (three of these). Baker: "Here you are."
2. **Market stall:** "You pick up a scarf." → S3. Seller: a round price (tens) → learner says the price back to check ("Twenty?"). Seller: "Yes."
3. **Souvenir shop:** "Two postcards and a magnet." → S3. Clerk: L2 (euros and cents, normal speed) → learner says it back. **(Extras on)** curveball: the clerk says a slightly different price; the learner catches it.
