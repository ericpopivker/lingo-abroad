# Level 1 · Shopping · Lesson 2: Finding Things (shared spec)

**Goal:** ask if a shop has something, ask where to buy it, find an ATM, and read the signs at the door. About 7 minutes.

This spec lists **meanings**, not words. Write each item in the target language as a polite local would say it in the destination country (see SKILL.md, Writing the items).

## Speak — what you say

| # | Meaning | When | Target-language note |
| :- | :------ | :--- | :------------------- |
| S1 | "Do you have <thing>?" | In any shop | Practice with everyday travel things (sunscreen, an umbrella, a phone charger). |
| S2 | "Where can I buy <thing>?" | Asking a local or a hotel clerk | |
| S3 | "Is there an ATM near here?" | You need cash | Use the word locals say (e.g. Italy: _bancomat_). |

## Listen — what locals say back

| # | Meaning | Situation |
| :- | :------ | :-------- |
| L1 | "Yes, over there." | Answering S1 (pointing) |
| L2 | "No, sorry, we don't have it." | Answering S1 |
| L3 | "At the <shop type>, on the corner." (e.g. "At the pharmacy, on the corner.") | Answering S2 |

## Read — what you'll see

| # | Meaning | Where |
| :- | :------ | :---- |
| R1 | ATM / Cash machine | Bank walls, stations (e.g. Italy: _Bancomat_) |
| R2 | Push / Pull | Shop and café doors; teach as a pair |
| R3 | Market (and its days) | Square signs, posters (e.g. Italy: _Mercato_) |

## Roleplay — 3 short scenes

1. **Small shop:** "It's sunny and you forgot sunscreen. Shopkeeper: greeting." → S1. Shopkeeper: L2 → learner: S2. Shopkeeper: L3 (at the pharmacy) → thank you.
2. **Pharmacy:** "At the pharmacy." → S1 (sunscreen). Pharmacist: L1 → learner: thank you.
3. **Cash:** "The market only takes cash. You stop a passer-by." → "excuse me" + S3. Passer-by: "Yes, straight ahead, on the right" (Sightseeing) or "Yes, over there." → thank you. **(Extras on)** curveball: the shop door says R2 (pull); the learner pushes; ask what the sign says.
