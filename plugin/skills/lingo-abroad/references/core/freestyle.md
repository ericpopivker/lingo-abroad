# Freestyle Conversation

Read this when the learner says "Freestyle" or "Let's chat in <language>". Rules from SKILL.md still apply.

An unscripted conversation in a **given situation**, using **only words the learner already knows**: the closest thing to the real trip. Start it when the learner says **"Freestyle"**, "Let's chat in <language>", or "Freestyle at <place>". Offer it in the What next? menu once the learner has done **at least 3 lessons**.

- **Give the situation:** pick one that fits the learned phrases (or use the place the learner named) and set it in one sentence, with a small goal: "You're at a bakery at 9 a.m. Get a pastry, pay, and leave politely." Play a **polite local**.
- **Only known words:** both you and the expected answers use **only phrases, replies and signs from lessons the learner has done**. No new vocabulary. Unlike practice roleplay, there's **no script**: vary the order, add small surprises using known phrases ("_Mi dispiace, è chiuso_", "_Un attimo_"), and react to what the learner says.
- If the learner wants to say something they haven't learned, help them do it with known phrases (pointing + _Questo, per favore_); if impossible, say so in one English sentence and move on.
- Speak slowly in **short sentences**.
- **Polite register** for both sides; never _Ciao_ or _tu_ from you.
- **Light corrections (recasts):** don't stop the conversation for every mistake. Repeat the learner's sentence correctly and continue ("Ah, _un caffè, per favore_. Certo!"). Stop to correct only an informal form or a phrase that would cause a real misunderstanding.
- **English safety net:** if the learner answers in English, give the version in the language, have them say it, and continue.
- **"Slower"**, "again" and "what does … mean?" always work.
- **Length:** about 3–5 minutes, or until the learner says "stop".
- **Ending feedback** (short, in English): did they reach the goal, **two things they did well**, and **up to two fixes** (with the correct phrase). Fixes go to **Weak**.
- **Progress:** counts for the streak; doesn't complete lessons or tests. In card mode print the card (log row Type `freestyle` if asked; counts may be estimates); in server mode call `save_lesson` with type `freestyle`.

**Places:** never the same place as the last freestyle or practice roleplay, and only places from topics the learner has done.
