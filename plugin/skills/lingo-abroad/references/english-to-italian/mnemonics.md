# English → Italian: Memory Tricks

Hand-made memory tricks for **English speakers** learning Italian, one per phrase, in alphabetical order. Not tied to lessons: look up the Italian phrase you're teaching. If it's listed, **use this trick** (and prefer this wording if it fits the spec's meaning). If only part of a phrase is listed (e.g. _giorno_ inside _Buona giornata_), reuse that part's trick. Otherwise make your own (see SKILL.md, Memory hooks).

Add new phrases in alphabetical order. Write look-alikes and word parts as plain text; say them naturally.

| Italian | Meaning | Memory trick |
| :------ | :------ | :----------- |
| Acqua naturale, per favore. | Still water, please. | _Acqua_ like aquarium; _naturale_ = natural, nothing added. |
| Alla prossima fermata. | At the next stop. | _Prossima_ = proximity, the next one; _fermata_ = where it stops ("stand firm"). |
| Allergeni / Contiene… | Allergens / Contains… | Look like allergens and contains. |
| Antipasti | Starters | _Anti_ = before (like ante-room), _pasto_ = meal: before the meal. |
| Aperto | Open | A camera's aperture is its opening. |
| Arrivederci | Goodbye | _Ri-vedere_ = to re-view, see again: "until we see each other again." |
| Arrivederci, buona serata! | Goodbye, have a nice evening! | _Serata_ grows from _sera_ (the serenade): the whole evening ahead. |
| Arrivi | Arrivals | _Arrivi_ = arrivals. |
| Attendere prego | Please wait | _Attendere_ like an attendant waiting on you. |
| Attenzione | Caution / Attention | Looks like attention. |
| Basta così, grazie. | That's all, thank you. | _Basta_ = enough: picture pushing away a full plate of pasta, "basta!" |
| Biglietteria | Ticket office | _Biglietto_ + _-eria_ = the ticket place (like a pizzeria). |
| Biglietti, prego. | Tickets, please. (conductor) | _Biglietti_ = billets; _prego_ = "pray, show them." |
| Binario | Platform / track | Two rails: binary. |
| Buona giornata! | Have a nice day! | _Giornata_ grows from _giorno_ (day): the whole day ahead. |
| Buonasera | Good evening | _Sera_ = evening: a serenade is sung in the evening. |
| Buongiorno | Good morning / Hello | _Buon_ = good, like a bon voyage; _giorno_ = day, like a journey or journal. Good day. |
| Buongiorno, mi dica. | Hello, how can I help? | _Dica_ like dictate: "dictate to me what you want." |
| Cassa | Cashier / Pay here | _Cassa_ = cash desk, related to cash. |
| Centro | City center | Center. |
| Certo! | Of course! / Sure! | Like certainly. |
| Che cos'è? | What is this? | _Cosa_ = thing; "what thing is it?" |
| Chiedo in cucina. | I'll check with the kitchen. | _Cucina_ = kitchen, like cuisine. |
| Chiuso | Closed | KYOO-zoh: "key, use it": you need a key because it's locked. |
| Contanti o carta? | Cash or card? | _Contanti_ from _contare_, to count: money you count out. |
| Convalidare il biglietto | Validate your ticket | Validate. |
| Coperto | Cover charge | _Coperto_ = covered: the "cover" for bread and the table setting. |
| Cosa mi consiglia? | What do you recommend? | _Consiglia_ like counsel: "what do you counsel me?" |
| Cosa prende? | What are you having? | _Prende_ from _prendere_, to take, like apprehend: "what will you take?" |
| Da quale binario parte? | Which platform does it leave from? | _Binario_ = two rails (binary); _parte_ = departs. |
| Deve convalidare il biglietto. | You must validate the ticket. | _Convalidare_ = validate: stamp it in the machine. |
| Dove devo scendere? | Where do I get off? | _Scendere_ = descend: step down off the bus. |
| Dove va? | Where are you going? (polite) | _Dove_: where does the dove fly? _Va_ = goes ("vamoose"). |
| È buonissimo! / È delizioso! | It's delicious! | _Buon-issimo_ = the very best "good" (_buon_ from _Buongiorno_); _delizioso_ looks like delicious. |
| È con… | It's made with… | _Con_ = with, like chili con carne. |
| È questo il treno per Firenze? | Is this the train to Florence? | _Treno_ = train; _questo_ = this (from "_Questo, per favore_"). |
| Ecco a Lei. | Here you are. | _Ecco_ like the old word "ecce" / "behold": "behold, for you." |
| Fatto in casa | Homemade | _Fatto_ = made, like a fact (something done); _casa_ = house: made in the house. |
| Fermata | Stop (bus/tram) | Where the bus stands firm. |
| Fuori servizio | Out of service | _Servizio_ = service; _fuori_ = out (picture a furious customer storming out). |
| Grazie / Grazie mille | Thank you / Thanks a lot | _Grazie_ like gratitude; _mille_ = a thousand, like a millennium: "a thousand thanks." |
| Guasto | Out of order (broken) | GWAH-stoh: the machine "gave up the ghost." |
| Ha prenotato? | Do you have a reservation? | _Prenotato_ = pre-noted: your name was noted down beforehand. |
| Il conto, per favore. | The bill, please. | _Conto_ like account, count: they count up what you owe. |
| Il servizio è incluso. | Service is included. | Looks like service and included. |
| In ritardo | Delayed | Tardy: late. |
| Ingresso | Entrance | Ingress = the way in. |
| Le consiglio… | I recommend… | _Consiglio_ = counsel, advice: "I counsel you to have…" |
| Metropolitana / M | Metro / subway | Metropolitan railway. |
| Mi dispiace, è chiuso. | I'm sorry, it's closed. | _Mi dispiace_ = "it displeases me" = I'm sorry. (_Chiuso_: "key, use it.") |
| Mi porta a questo indirizzo, per favore? | Can you take me to this address, please? (polite) | A porter carries you; _indirizzo_ = directions to the address. |
| Mi scusi | Excuse me / Sorry | _Scusi_ sounds like "excuse": ex-SKOO-se me. |
| Naturale o frizzante? | Still or sparkling? | _Frizzante_ sounds like fizzy. |
| Non toccare | Do not touch | _Toccare_ like touch (a toccata is a "touch" piece on keys). |
| Paghiamo separatamente. | We'll pay separately. | Looks like separately. |
| Partenze | Departures | Trains part = departures. |
| Permesso | Excuse me (may I pass?) | Like permission: asking permission to pass. |
| Piatto del giorno | Dish of the day | _Piatto_ = plate, like platter; _giorno_ = day (from _Buongiorno_). |
| Posso pagare con la carta? | Can I pay by card? | _Pagare_ = to pay; _carta_ = card (like a carton). |
| Posteggio taxi | Taxi rank | Taxis wait at their post. |
| Prego. | You're welcome. | Sounds like "pray, go ahead": you're gracious about it. |
| Prego? | Yes? / What would you like? | Same word, rising tone: "pray, go on, what can I get you?" |
| Primi / Secondi | First courses / Second courses | Primary and secondary: first the pasta, second the meat or fish. |
| Privato | Private | Looks like private. |
| Quale linea va a …? | Which line goes to …? | _Linea_ = line; _quale_ = which ("qual-ity: which kind?"). |
| Quanto costa per il centro? | How much is it to the center? | _Quanto_ = quantity, how much; _costa_ = costs; _centro_ = center. |
| Questo autobus va a …? | Does this bus go to …? | _Autobus_ = bus; _va_ = goes. |
| Questo, per favore. | This one, please. | _Per favore_ = "as a favor": "do me a favor." |
| Ricevuta | Receipt | Looks like received: proof it was received. |
| Riservato | Reserved | Looks like reserved. |
| Scontrino | Receipt (the small till slip in cafés and shops) | Picture a tiny contract, a "con-tr-ino", for your coffee. In many cafés you pay first and hand the _scontrino_ to the barista. |
| Sì / No | Yes / No | _Sì_ sounds like "see? yes!" |
| Si fermi qui, per favore. | Stop here, please. (polite) | _Fermi_: stand firm = stop; _qui_ = here ("kweeck, here!"). |
| Si figuri. | Don't mention it. | "Figure it's nothing." |
| Si prega di… | Please… (start of a notice) | _Prega_ = pray, as in "I pray you…": a polite request. |
| Sì, è questo. / No, è quello. | Yes, it's this one. / No, it's that one. | _Quello_ = that one over there (point!). |
| Sì, va al centro. | Yes, it goes to the center. | _Va_ = goes; _centro_ = center. |
| Siamo arrivati. | We've arrived. | _Arrivati_ = arrived. |
| Solo andata o andata e ritorno? | One-way or return? | _Solo_ = only the going: solo trip out. |
| Sono allergico / allergica a… | I'm allergic to… | Looks like allergic; _-o_ for a man, _-a_ for a woman. |
| Sono vegetariano / vegetariana | I'm vegetarian | Looks like vegetarian; _-o_ for a man, _-a_ for a woman. |
| Sottopassaggio | Underpass (to the platforms) | Sub-passage: the passage below. |
| Tabacchi (big "T" sign) | Tobacconist; sells bus and metro tickets | Tobacco shop, and tickets too. |
| Tutto bene? | Is everything all right? | _Tutto_ = all, like total; _bene_ like benefit: all good? |
| Un attimo. | One moment. | An _attimo_ is a tiny atom of time. |
| Un biglietto per Firenze, andata e ritorno. | A return ticket to Florence. (one-way: _solo andata_) | _Andata_ = the going (andante is a walking pace); _ritorno_ = return. |
| Un biglietto, per favore. | One ticket, please. | A billet / little bill: a ticket. |
| Un tavolo per due, per favore. | A table for two, please. | _Tavolo_ = table (both from Latin _tabula_); _due_ like a duet: two. |
| Uscita | Exit | oo-SHEE-tah: picture staff saying "shoo!" toward the exit. |
| Va bene | OK / That's fine | _Bene_ like benefit: "it goes well." |
| Vegetariano | Vegetarian | Looks like vegetarian. |
| Vietato fumare | No smoking | _Vietato_ like vetoed = forbidden; _fumare_ like fumes = smoke. |
| Vorrei… | I'd like… | _Vorrei_ comes from _volere_, to want, like volition: "my volition would be…", the polite "I would like". |
